# Store listing (English)

Used for the Chrome Web Store, Microsoft Edge Add-ons and Firefox Add-ons (AMO). The name and the short description are the extension's own strings (`extension/public/_locales/en/messages.json`); a test keeps this file and those strings equal.

## Name

Kasi Download Manager

## Short description (132 characters at most)

Send downloads to Kasi.

## Long description

Kasi is a download manager for Windows. This extension is its companion for your browser: it hands the files you download over to the Kasi desktop app, which splits them into parts, downloads them faster, and resumes them exactly where they stopped if your connection drops.

What the extension does

- Takes the downloads you choose. The file types come from Kasi's settings (archives, disc images, installers, video and audio by default). Smaller files, excluded sites and anything you hold a key for stay with the browser.
- Adds three right-click items: "Download with Kasi" on a link or media, and "Download all links" and "Download selected links" on a page. Kasi then shows a list so you pick what to download.
- Lets you switch it off from the toolbar popup. Hold Alt (or the key you chose in Kasi) while you click a link to let the browser download that one file itself.
- Tells you plainly when Kasi is not running or not installed, and in that case the browser simply downloads the file as it always does.

What it does not do

- It does not send your browsing history, the pages you visit or your downloads to MartSoft Solutions or to anyone else. Everything it reads goes only to the Kasi app on your own computer.
- It has no ads, no analytics and no remote code.

You need the Kasi desktop app for Windows. Without it this extension does nothing except show "Kasi is not connected".

## Single purpose

Send the downloads you choose from the browser to the Kasi download manager installed on the same computer.
