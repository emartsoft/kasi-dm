# M2.9 Plan: main window and job views (`Kasi.App`)

- **Phase:** M2 ([`plan.md`](../../plan.md) section 5)
- **Requirements:** `KASI-UI-001`, `UI-003`, `UI-006`, `UI-007`, `UI-008`, `UI-010`, `KASI-NFR-006` (groundwork), `KASI-NFR-017` (groundwork) ([TRD](../specs/KASI-TRD-2026-001.md) sections 12.1 to 12.3; wireframes `docs/wireframes/`)
- **Test cases:** `TC-UI-002`, `TC-UI-005`, `TC-UI-006` (view-model half), `TC-UI-007` (names and keyboard; the Narrator and Accessibility Insights runs are manual until FlaUI, M2.13)
- **ADR:** `docs/adr/0024-main-window-and-job-views.md`
- **Dependencies:** none new (`Avalonia.Controls.DataGrid` is already referenced).
- **Delivery:** four PRs. **9a** the window: toolbar, sidebar, columns, search, status bar, shortcuts, delete confirmation. **9b** persistence: column layout, sort order and the theme override (`UI-006`, `UI-007`, `TC-UI-005`). **9c** the details window: segment map, connection table and log tail, fed by two new engine events (decision 1). **9d** performance and accessibility: a 10,000-row view-model budget test, keyboard and automation-name coverage, Mica.
- **Status:** approved by the owner on 2026-10-23 (decisions 1 and 2); 9a and 9b implemented.

## Decisions (approved)

1. **Engine events for the details window.** Two small events in `Kasi.Core`/`Kasi.Engine`, with no UI dependency: a throttled **segment snapshot** (index, range, bytes written and speed per connection, at least twice a second) and a short **job-log line** (probe result, retry, split, resume; ranges and codes only, never a URL or a path). Without them the map could only follow the 2-second checkpoint, which cannot meet `UI-003`.
2. **Queue controls.** Start queue, Stop queue, Scheduler and the Night-queue tab are drawn as in the wireframe and **disabled until the scheduler exists (M2.10)**. Queue names are in the sidebar; schedule times appear with M2.10.
3. **Stop.** Until M2.10 Stop does what Pause does (a queue that would restart the job by itself does not exist yet).
4. **Delete.** Always asks (with "Also delete the downloaded files" and "Do not ask again"); Delete completed asks too and never touches files.
5. **Mica.** The wireframe's Mica backdrop is a polish item for 9d, since the plain Fluent window already follows the theme.

## 9a: what it builds

- Toolbar in the wireframe's order (Add URL, Resume, Pause, Stop, Delete, Delete completed, Start queue, Stop queue, Scheduler, Speed limit, Settings) plus a search box (`UI-008`).
- Sidebar: status filters with live counts (All, Active, Finished, Unfinished), then categories, then queues; one entry selected at a time.
- Grid columns: File name, Size, Progress (bar and percent), Speed, Time left, Status, Date added, Category, sortable by their numbers (not their text), resizable and reorderable.
- Status bar: total speed, active and queued counts, the speed limit, and whether a browser extension is connected.
- Keyboard: Ctrl+N, Ctrl+F, Space, Delete, F5, Enter; double-click opens a completed file or asks for the details window.
- Every control has an automation name; every string is in `Strings.resx`.
