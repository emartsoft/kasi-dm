## 1. Scope & Decisions

M2.7 mitigates the critical project risk: *"Chrome Web Store rejects or delays the extension"* (`plan.md` risk register) by preparing production submission packages early in the alpha phase:

- **Store Target Profiles:**
  - Chrome Web Store (Chromium MV3 zip)
  - Microsoft Edge Add-ons (Chromium MV3 zip)
  - Mozilla Add-ons (AMO Firefox MV3 zip / xpi)
- **Clear Permission Justifications (`TRD 9.1`):** Detailed justifications for store reviewers:
  - `<all_urls>`: Required to read origin cookies and headers so downloads can resume with identical authentication.
  - `downloads`: Required to pause and cancel matching browser downloads upon desktop handoff.
  - `webRequest`: Required to observe response headers (Content-Disposition, Content-Type) without blocking.
  - `nativeMessaging`: Required to communicate with `Kasi.NativeHost.exe`.
- **Privacy Policy (`KASI-NFR-013`):** Explicitly specifies that user URLs, cookies, and personal data are never sent to external servers and remain strictly on the user's local machine.

## 2. Architecture & Design

### 2.1 Asset & Metadata Layout (`docs/store/`)

```text
docs/
├── legal/
│   └── privacy-policy.md              # Privacy policy for store listings
└── store/
    ├── permission-justifications.md   # Per-permission justification texts
    ├── descriptions/
    │   ├── en-US.md                   # Short description, full feature overview
    │   └── sw.md                      # Swahili listing description (future-proof)
    └── assets/
        ├── icon-16.png, icon-32.png, icon-48.png, icon-128.png
        ├── promo-small-440x280.png
        └── promo-marquee-1400x560.png
```

### 2.2 Automated Packaging Script (`extension/scripts/package.ts`)

- Runs clean build (`npm run build`).
- Validates manifest keys (verifies developer keys or debug flags are omitted).
- Creates `dist/kasi-extension-chromium-v1.0.0.zip` and `dist/kasi-extension-firefox-v1.0.0.zip`.

## 3. Verification

- `ManifestLintTests`: Verifies manifests pass Mozilla `addons-linter` and Chrome Web Store requirements (no prohibited MV3 keys, valid icon resolutions).
- Package integrity verification: Asserts zip archives contain only required distribution assets without development source maps or test fixtures.
