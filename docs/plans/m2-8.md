## 1. Scope & Decisions

M2.8 constructs the core application architecture in `src/Kasi.App` (Avalonia + MVVM), connecting the background download engine and IPC pipe with desktop UI controls:

- **Composition Root:** Uses `Microsoft.Extensions.Hosting` (`IHost`, `IHostedService`) to manage the lifecycles of `DownloadEngine`, `KasiPipeServer`, and Avalonia desktop application.
- **Single Instance & Argument Handoff (`KASI-SYS-005`, `TC-SYS-006`):**
  - Uses a global Windows Mutex (`Global\Kasi-SingleInstance-<SID>`).
  - If an instance is already running, secondary process forwards command-line arguments (e.g. `--tray`, or download URLs) to the running instance over the named pipe and exits immediately.
- **`UiBatchDispatcher` (250 ms Throttle):** High-throughput downloads trigger hundreds of progress updates per second. `UiBatchDispatcher` buffers engine events and dispatches aggregated UI updates to Avalonia's UI thread every **250 ms**, ensuring fluid 60 fps rendering without UI thread starvation.
- **System Tray (`KASI-UI-004`, `TC-UI-003`):** Provides global status icon with context menu (aggregate speed, Pause all, Resume all, speed limit presets, Open Kasi, Quit). Functions seamlessly when the main window is closed.
- **Windows Toast Notifications (`KASI-UI-005`, `TC-UI-004`):** Fires native Windows toast notifications on download completion or failure, equipped with "Open file" and "Open folder" action buttons.
- **Add Download & Duplicate Prompt (`KASI-UI-002`, `TC-UI-001`, `TC-ENG-021`):**
  - Pre-fills URL, suggested filename, target directory, category, queue, and connection count.
  - When a duplicate download is detected (`DuplicateDetector`), prompts the user with legal choices: **Resume**, **Overwrite**, or **AutoRename** (`TC-ENG-021`).

### 2.2 UI Event Batching (`UiBatchDispatcher`)

```csharp
public sealed class UiBatchDispatcher : IAsyncDisposable
{
    private readonly PeriodicTimer _timer = new(TimeSpan.FromMilliseconds(250));
    private readonly ConcurrentQueue<EngineEvent> _events = new();

    public void Enqueue(EngineEvent evt) => _events.Enqueue(evt);

    private async Task ProcessLoopAsync(CancellationToken ct)
    {
        while (await _timer.WaitForNextTickAsync(ct))
        {
            var batch = DrainQueue();
            if (batch.Count > 0)
            {
                await Dispatcher.UIThread.InvokeAsync(() => ApplyBatchToViewModels(batch));
            }
        }
    }
}
```

## 3. Verification

- **`SingleInstanceTests` (`TC-SYS-006`):**
  - First instance acquires mutex and opens pipe.
  - Second instance detects mutex, sends URL via pipe, and exits code 0.
  - First instance receives URL and opens Add Download view model.
- **`UiBatchDispatcherTests`:**
  - 10,000 progress events enqueued over 1 second $\to$ UI thread invoked exactly 4 times ($250\text{ ms}$ intervals).
- **`TrayIconTests` (`TC-UI-003`):**
  - Main window closed $\to$ tray icon remains active; invoking "Pause all" pauses engine jobs.
- **`ToastNotificationTests` (`TC-UI-004`):**
  - Verifies toast action activation triggers file/folder execution commands.
- **`AddDownloadViewModelTests` (`TC-UI-001`, `TC-ENG-021`):**
  - Verifies input fields map to created `Job` record.
  - Verifies duplicate detection triggers prompt and handles Resume, Overwrite, and AutoRename paths correctly.
