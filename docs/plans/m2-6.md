## 1. Scope & Decisions

M2.6 configures native host registration in the Windows Registry per user (`HKCU`), enabling browsers to discover and launch `Kasi.NativeHost.exe` while strictly restricting access to legitimate extension IDs:

- **Per-User Registry Keys (No Admin / UAC Required):**
  - **Google Chrome:** `HKCU\Software\Google\Chrome\NativeMessagingHosts\com.martsoft.kasi`
  - **Microsoft Edge:** `HKCU\Software\Microsoft\Edge\NativeMessagingHosts\com.martsoft.kasi`
  - **Mozilla Firefox:** `HKCU\Software\Mozilla\NativeMessagingHosts\com.martsoft.kasi`
- **Security Allowlists (`TC-BRW-007`, `NFR-010`):**
  - Chromium manifests include `allowed_origins` with the exact Web Store extension IDs (`chrome-extension://<id>/`).
  - Firefox manifests include `allowed_extensions` with the exact AMO add-on ID (`kasi@martsoft.co.ke`).
  - Any message sent from an un-allowlisted extension ID is immediately blocked and refused by the browser's native messaging security layer before reaching `Kasi.NativeHost.exe`.

## 2. Architecture & Design

### 2.1 Manifest Specifications

**Chromium (`com.martsoft.kasi.chrome.json`):**
```json
{
  "name": "com.martsoft.kasi",
  "description": "Kasi Download Manager Native Messaging Host",
  "path": "Kasi.NativeHost.exe",
  "type": "stdio",
  "allowed_origins": [
    "chrome-extension://<CHROME_STORE_EXTENSION_ID>/",
    "chrome-extension://<EDGE_STORE_EXTENSION_ID>/"
  ]
}
```

**Mozilla Firefox (`com.martsoft.kasi.firefox.json`):**
```json
{
  "name": "com.martsoft.kasi",
  "description": "Kasi Download Manager Native Messaging Host",
  "path": "Kasi.NativeHost.exe",
  "type": "stdio",
  "allowed_extensions": [
    "kasi@martsoft.co.ke"
  ]
}
```

### 2.2 Registration Automation (`scripts/Register-NativeHost.ps1`)

Automates developer and local test registration:
- Computes absolute path to `Kasi.NativeHost.exe`.
- Generates JSON manifests with absolute host executable path.
- Sets registry default values in `HKCU\Software\[Browser]\NativeMessagingHosts\com.martsoft.kasi` pointing to manifest file paths.
- Provides `-Unregister` switch to clean up registry on uninstall.

## 3. Verification

- **`RegistryRegistrationTests`:** Validates registry keys and values are correctly written and removed under `HKCU`.
- **`SecurityAllowlistTest` (`TC-BRW-007`):**
  - Injected browser test attempts native port connection from a rogue/unregistered extension ID.
  - Asserts browser throws error `"Access to the specified native messaging host is forbidden"`, and `Kasi.NativeHost.exe` process is never launched.
