## 1. Scope & Decisions

M2.5 builds the user-facing capabilities of the browser extension:

- **Connection Status Polling (`KASI-BRW-006`):** Extension background periodically checks native port health. If the native host disconnects or fails to respond, the status indicator turns red within **5 seconds** in both popup and badge.
- **Context Menus (`KASI-BRW-004`):**
  - Right-click on a hyperlink $\to$ "Download with Kasi" (sends `addDownload`).
  - Right-click on media/image $\to$ "Download with Kasi" (sends `addDownload`).
  - Right-click anywhere on page $\to$ "Download all links" and "Download selected links".
- **Out-of-Process Link Picker (`KASI-BRW-005`, `TRD 9.5`):** The extension gathers URLs, text, and anchors from the DOM via content script, packages them into an `addBatch` message, and sends them to Kasi. The interactive filtering and multi-selection UI runs in the Kasi desktop application, ensuring pages with thousands of links never cause browser tab lag.
- **Clipboard Monitoring (`KASI-BRW-007`):** Disabled by default. When enabled in options, clipboard text is checked for supported download URLs and passed to Kasi.

## 2. Architecture & Design

### 2.1 Component Layout (`extension/src/`)

```text
extension/src/
├── popup/
│   ├── popup.html                     # Status dot, interception toggle, media list
│   └── popup.ts                       # Reads port state, toggles rule interception
├── options/
│   ├── options.html                   # Clipboard capture toggle, opens desktop app
│   └── options.ts
├── content/
│   ├── link-collector.ts              # Scrapes DOM anchors, resolves relative hrefs
│   └── selection-collector.ts         # Scrapes links in user selection range
├── background/
│   ├── context-menus.ts               # contextMenus.create and onClicked dispatch
│   ├── heartbeat.ts                   # 5-second connection health monitor
│   └── clipboard-watcher.ts           # Optional clipboard URL polling
```

### 2.2 Link Extraction Protocol (`addBatch`)

The content script collects DOM `<a>` elements, resolves absolute URLs via `new URL(anchor.href, document.baseURI)`, bundles them with anchor text, and sends them to background:

```json
{
  "v": 1,
  "id": "uuid-...",
  "type": "addBatch",
  "pageUrl": "https://example.com/downloads",
  "pageTitle": "Download Archive",
  "links": [
    { "url": "https://example.com/doc1.pdf", "text": "Document 1" },
    { "url": "https://example.com/doc2.pdf", "text": "Document 2" }
  ]
}
```
